# Agent instructions (crypto-vdf-js)

## Git branches

Do not name a branch `cursor`, and do not put `cursor` in a branch name.
Name the branch after the change.

## Authorship — no LLM / AI attribution

Do **not** attribute any work in this repository to Cursor, Claude, Grok, ChatGPT, Copilot, Codex, Gemini, or any other LLM, AI assistant, or AI coding tool.

Forbidden in commits, pull requests, tags, releases, issues, comments, file headers, changelogs, and documentation:

- `Co-authored-by: …` trailers naming an AI/LLM tool or agent
- `Made with …`, `Generated by …`, `Assisted by …`, or similar credits for AI tools
- Author / committer identity set to an AI tool email or name

Commits and pull requests are authored only by the human maintainer.
When creating or amending commits, do not add AI co-author trailers.
